# zukan-assets

Icon + data assets for [`zukan`](https://github.com/lazywalker/zukan), the terminal
monster sprite tool (basically a Monster Hunter version of those pokemon
scripts).

Pulls together monster icons from 11 MH titles, normalizes them into
`icons/<game>/<slug>.png`, and bolts on per-game hunter-notes text plus
structured numeric data (weaknesses, resistances, ailments, rewards, item info)
from a couple of community APIs.

## Repository layout

```
zukan-assets/
├── data/        # build output (gitignored — regenerated by tools/build.py)
├── icons/       # build output (gitignored — regenerated by the pipeline)
├── source/      # vendored + fetched inputs (see source/README.md)
├── tools/       # the ETL pipeline (see tools/README.md for scripts, build, icon spec, CI)
└── .github/workflows/   # check-upstream.yml + release.yml
```

`data/` and `icons/` are **not committed** — they're deterministic products of
`source/` + the pipeline scripts. Run `python3 tools/build.py` to regenerate
them locally. CI publishes them as a Release artifact (tar.gz) for downstream
consumers like the `zukan` terminal tool.
